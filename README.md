Bike Sales Analysis Dashboard

📌 Project Overview

This project analyzes bike sales data using Microsoft Excel and presents the findings through an interactive dashboard. The objective is to identify sales trends, customer demographics, and factors influencing bike purchases.

🛠️ Tools & Technologies

- Microsoft Excel
- Excel Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Interactive Dashboard

🔍 Analysis Performed

- Analyzed overall bike purchase trends

- Compared purchases across different regions
- Analyzed customer characteristics and purchasing behavior
